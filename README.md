## 它解决什么问题

目标编号在不同界面不一致且无人收口；威胁评级是读字段加三元判断，不可复算。

## 做 / 不做

| 做 | 不做 |
|---|---|
| 实体登记、多源去重与置信度融合 | 不内建实体类型名 |
| 编号规则与跨视图一致性检查 | 不做打击方案与成功率 |
| 威胁评级引擎（因子可复算、阈值可配） | 不做地理符号与配色 |
| 优先级排序与打击序列 | 不做自然语言分析文案 |
| 轨迹写入 / 区间查询 / 抽稀 / 时间轴 / 预测 |  |
| 动作状态机与情报关联链 |  |
